# Private tentative placement

Owner Decision Atlas 2.6 (#155) supersedes the public preview of #18. A proposed placement stays private to the player who made it. Opponents, the shared board, and public wire snapshots never see its tiles, letters, coordinates, words, or evaluation. They only see a move once the server accepts it.

The active phone still sends its selected placement IDs, coordinates, and assigned blank letters as a sequenced `preview` command. The native session checks authenticated identity, sequence, active turn, rack ownership, placement count, coordinates, and blank assignments before deriving letters. Unplaced rack letters never enter a preview. The derived tiles, plus the authoritative evaluation on hex boards, come back only in that player's own projection as `PlayerSnapshot.own_preview`. `PublicSnapshot` has no preview field, and strict decoders on both sides reject one. Every other projection, including the shared board's, is byte-identical whether or not a preview exists. Legacy or modified clients that still send `preview` therefore reveal nothing to anyone else.

The shared board renders only accepted tiles. Edits replace the whole private echo, and cancel sends an empty preview. Commit submission suspends publication before sending the authoritative command. Rapid edits are coalesced for 100 ms, and an active draft refreshes every 500 ms.

Native echoes expire after two seconds without a refresh. Disconnects and reconnects clear them immediately. A disconnected player's projection never carries an echo, so recovery replay cannot resurrect one. Pass, exchange, timeout, and commit acceptance clear the echo along with the turn transition. Stale sequences cannot overwrite newer packets, and wrong-turn or wrong-player commands cannot mutate state. Canonical snapshots, replay reports, and history never contain preview data.

Native tests cover expiry, cancel reordering, rejected packets, disconnect/reconnect/recovery fencing, and byte-identical observer projections after a legacy preview command (`legacy_preview_commands_stay_private_to_the_proposing_player`). Browser tests drive real phone edits. They wait for the owner's own echo, then assert that the shared board shows no tentative tile. The wire observer rejects any `own_preview` addressed to another player or to the board.
